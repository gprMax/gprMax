============================
Radar cross-section examples
============================

``pec_sphere`` contains equivalent hash-command and Python API models. They
demonstrate a discrete plane-wave TFSF source, a conventional equivalent-
current NTFF transform, monostatic backscatter RCS over a frequency sweep, and
comparison with the analytical PEC-sphere Mie series. Generated HDF5, VTK, and
plot files should not be committed to this directory.
