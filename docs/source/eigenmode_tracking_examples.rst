Geometry-only eigenmode tracking examples
==========================================

Examples 1–9 show sixteen tracked modes for every PEC/copper/dielectric
and rectangular/square/cylindrical combination. Examples 10 and 11
show a frequency crossing and persistent doublets crossing in a material
parameter sweep. Each case includes executable code and recorded galleries.
